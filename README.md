# Фокус — мобильный таймер учёта времени

Статический сайт-PWA для телефона. Таймер и список сессий работают в браузере; интернет нужен для первой загрузки сайта. Сессии остаются только на том устройстве и в том браузере, где их создали.

## Публикация через GitHub Pages

1. Создайте отдельный репозиторий на GitHub, например `focus-time-tracker`.
2. Загрузите в корень репозитория содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **GitHub Actions**. В workflow есть файл `.github/workflows/pages.yml`.
5. Дождитесь успешного запуска в **Actions** и откройте адрес вида `https://ВАШ-ЛОГИН.github.io/focus-time-tracker/`.
6. На телефоне откройте адрес и добавьте приложение на главный экран.

GitHub Pages публикует содержимое в интернете. Не храните в репозитории клиентские проекты, переписку, договоры, счета, личные данные и файлы учёта.

## Выгрузка в Excel

В разделе «Сессии на этом устройстве» нажмите «Скачать CSV для Excel». Сохраните CSV, откройте его в Excel и перенесите строки в конец таблицы листа «Журнал» в `Трудозатраты.xlsx`. Колонки CSV соответствуют полям журнала: клиент, ID проекта, дата, начало, конец, фокус-время, этап, задача, комментарий. После импорта проверьте распознавание времени и даты Excel.

Экспорт пока создаёт выгрузку всех сессий, накопленных в браузере. Избегайте повторного переноса одного файла, чтобы не задвоить записи.

## Локальный просмотр

Откройте `index.html` в браузере для визуального просмотра. Для установки PWA нужен HTTPS, например опубликованный GitHub Pages адрес. Браузер не даёт установить PWA из обычного `file://`.

## Ограничения первой версии

- нет синхронизации между компьютером и телефоном;
- браузерные уведомления и точность таймера в фоне зависят от ОС и энергосбережения; для надёжного сигнала оставьте вкладку открытой;
- CSV нужно вручную импортировать в общую Excel-книгу;
- параметры перерыва в первой версии заданы как 5 минут и 15 минут после каждого четвёртого цикла.
